# ToolPayload

**中文简介：** 离线分析 MCP 工具结果大小、定位占用字段并检查响应预算的命令行工具。

**English overview:** An offline CLI that measures MCP tool result size, identifies large fields, and enforces response budgets.

## 使用 / Usage

需要 Node.js 22+。程序源码在 `src/`；构建后使用 `dist/cli.js`。

Requires Node.js 22+. Source lives in `src/`; after building, run `dist/cli.js`.

```text
npm ci
npm run build
node dist/cli.js --help
```
